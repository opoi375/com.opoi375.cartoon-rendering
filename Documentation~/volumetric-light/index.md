# 体积光（上帝光 / 光柱）

`CartoonRendering/PostProcessing/VolumetricLight` 在屏幕空间做光线步进，逐点采样主光阴影图，用 Beer 定律累积散射 —— 阳光穿过窗缝、树冠、云隙时出现的那一道道可见光柱。

它不是屏幕空间的径向模糊伪造：每一步都真的在问「这个空间点被遮挡了吗」，所以光柱形状完全由场景几何与光影决定，遮挡物一动光柱就跟着动。

## 特点

- **真正的体积散射** —— 沿视线步进 + 主光阴影图采样，不是后期糊出来的光晕
- **半分辨率 + 深度感知双边上采样** —— 3×3 帐篷核按深度相似度加权，前景几何体边缘不会渗出光晕
- **Henyey-Greenstein 相位函数** —— 迎光看时前向散射会自然拉出亮斑，背光时衰减，可调各向异性
- **高度雾** —— 指数高度衰减让光柱贴地，不会整片天都糊着
- **尘埃噪声** —— 可选 3D 值噪声，光柱有絮状 / 浮尘感，可漂移
- **卡通分层** —— 把散射亮度量化成 N 档，得到漫画式的硬边光带，这是本包的风格化选项
- **调试视图** —— 一键看阴影采样结果 / 步数 / 场景距离，阴影接不上一眼就能看出来

## 快速设置

1. 把 Feature 装进渲染器：菜单 **Tools > Volumetric Light > Setup In Renderer**
   （或手动在 Renderer Features 里 Add "Volumetric Light"）
2. 场景里放一个 **Global Volume**，Profile 里 **Add Override > CartoonRendering > Volumetric Light**
3. 把 **Intensity** 从 0 调到 1 左右
4. 确保场景里有**主方向光**且开启了阴影（URP 管线资产里 Main Light Shadows 要勾上）
5. 加一点 **Bloom**，阈值 0.9 左右，光柱会带辉光

> **Intensity 默认是 0。** 这是刻意的：`VolumeManager` 对没有 Volume 覆盖的组件也会返回一个默认实例，默认非 0 会变成「没放 Volume 也生效」，影响所有场景。

## 参数速查

### 主控

| 参数 | 说明 |
| --- | --- |
| `Intensity` | 总强度，0 = 完全关闭（默认） |
| `Tint` | 散射着色，一般取光源颜色 |
| `Density` | 散射系数（每米消光量）。0.01 ~ 0.05 是常见区间 |
| `Anisotropy` | HG 相位函数 g。正数 = 前向散射（迎着光最亮），0 = 各向同性 |

### 范围与高度雾

| 参数 | 说明 |
| --- | --- |
| `Max Distance` | 最远步进距离，主要的性能旋钮 |
| `Distance Fade` | 从最远距离的百分之几处开始淡出，避免硬边 |
| `Height Start` | 高度雾起始高度（世界 Y，一般填地面高度） |
| `Height Falloff` | 每升高 1/该值 米密度衰减到 1/e。0 = 关闭高度雾 |

### 阴影

| 参数 | 说明 |
| --- | --- |
| `Shadow Strength` | 阴影对散射的压制比例。1 = 最锐利，0 = 忽略阴影（变成均匀雾） |
| `Shadow Bias` | 采样点沿指向光源方向的偏移。太小会摩尔纹闪烁，太大会让光柱离地 |

### 质量

| 参数 | 说明 |
| --- | --- |
| `Step Count` | 步进次数。24 ~ 36 是质量与开销的平衡点 |
| `Jitter` | 步进起点抖动强度，打散步进条带。静态抖动，靠双边上采样抹平 |
| `Softness` | 上采样抽头间距。1 = 相邻纹素；调大等于加一层模糊 |

### 尘埃噪声

| 参数 | 说明 |
| --- | --- |
| `Noise Strength` | 0 = 均匀介质（干净但「塑料」），0.2 ~ 0.4 比较像浮尘 |
| `Noise Scale` | 噪声频率（每米），0.05 ~ 0.2 像空气尘埃 |
| `Noise Speed` | 噪声漂移速度（米/秒），0 = 完全静止 |

### 风格化

| 参数 | 说明 |
| --- | --- |
| `Banding` | 卡通分层档数。0 = 关闭，4 ~ 6 能出漫画式硬边光带 |

## 调试视图

菜单 **Tools > Volumetric Light > Debug/** 下有四个模式（也会覆盖整屏，不叠加）：

| 模式 | 看什么 |
| --- | --- |
| `Shadow` | **最重要**：主光阴影采样结果。要有明暗分区才说明关键字接上了 —— **整屏纯白就说明阴影没生效，光柱已经退化成均匀雾** |
| `Steps` | 步数热力图 |
| `Scene Depth` | 场景距离（按最远步进距离归一化），用来确认步进范围是否合理 |

排查顺序：`Shadow` → 看阴影对不对，`Scene Depth` → 看范围对不对，`Off` → 回正常。

## 内景光柱实战（工厂演示）

演示工程的 `Assets/Scenes/FactoryInterior.unity`（构建脚本见[编辑器工具一览](/tools/)的「工厂内景演示脚本」）把这套参数落在了室内场景上，几条踩过的坑：

- **主光必须保持 `Mixed`。** 体积光靠主光的**实时阴影图**算光柱；一旦把太阳设成 `Baked`，运行时就没有实时阴影了，阴影采样恒为「受光」，光柱会整体消失、退化成均匀雾。`Mixed + Baked Indirect` 刚好：间接光烘焙，直接光与阴影保持实时
- **间接光强度要敢往大调。** 实测 `Indirect Scale = 1.0` 时贴图值只有 ~0.05，在暗面上根本看不出来，推到 3 ~ 4 才能把暗面从「纯黑」抬到「深灰」
- **别正对太阳看。** HG 前向散射的峰值会把整屏糊成一片奶白，侧向看才有根根分明的光柱
- **相机自己待在阴影里。** 相机处在受光位置时整条视线上的雾都是亮的，光柱与背景没有亮度差
- **窗户做成竖框 + 横框的多格窗**，入射光被切成规整的光柱阵列，这是体积光最好看的形态
- **低角度太阳**（仰角约 26°）光柱才拉得长，能铺满整个室内

## 实现要点

1. **光线重建** —— 从深度图还原视图空间位置，按透视 / 正交分别构造世界空间光线（正交相机位置不在光线上，不能拿它当原点）
2. **步进** —— 范围 `[近平面, min(场景距离, 最远距离)]`，每步把世界坐标转到主光阴影坐标采样可见度
3. **Beer 定律** —— `T *= exp(-σ·dt)`，累积 `光照 × 可见度 × σ × T`
4. **HG 相位函数** —— 乘 4π 归一化，`g = 0` 时结果为 1
5. **抖动** —— 静态 IGN 偏移步进起点。逐帧变化的抖动在没有 TAA 时会闪，静态抖动靠上采样模糊抹平
6. **上采样** —— 散射写进半分辨率 RT，alpha 通道顺便存场景视图深度，合成时用深度差做双边权重

### 关于阴影关键字

`_MAIN_LIGHT_SHADOWS` / `_MAIN_LIGHT_SHADOWS_CASCADE` 是 URP 设置的**全局**关键字。本包在声明 `multi_compile` 之外，还会在 C# 侧按 `UniversalShadowData` **显式设置材质的局部关键字** —— 全局关键字的隐式回退在某些管线状态下会失效，一旦失效光柱会整体消失、退化成均匀雾，而且不会报任何错，非常难查。

这正是 `Debug/Shadow` 视图存在的理由。

## 性能

主要开销是「像素数 × 步进次数 × 阴影采样次数」，所以：

- **分辨率**：Feature 上的 `Resolution` 默认 `Half`。改成 `Full` 开销翻四倍，只在光柱边缘需要极干净时用
- **步数**：`Step Count` 是线性开销
- **最大距离**：`Max Distance` 决定了有多少步是浪费在看不见的远处
- **噪声**：`Noise Strength > 0` 时每步多算一次 3D 值噪声，不需要浮尘感就调成 0
- **不激活时零开销**：`Intensity = 0` 时渲染通道直接 return，不分配 RT 也不提交任何绘制

## 已知限制

- **只支持主方向光。** 聚光灯 / 点光需要遍历附加光并采样各自的阴影切片，本包暂不覆盖
- **需要 URP 的深度图。** 通道通过 `ConfigureInput` 声明了依赖，管线资产没开 Depth Texture 也会自动生成
- 正交相机可用（光线重建做了分支），但演示与调参都是按透视做的
