# 屏幕空间间接光照（SSIL）

`CartoonRendering/PostProcessing/SSIL` 实现了论文 *Screen Space Indirect Lighting with Visibility Bitmask*（Therrien / Levesque / Gilet, arXiv:2301.11376）：一趟屏幕空间追踪同时产出**环境光遮蔽（AO）**与**带颜色的间接光**。纯屏幕空间、零预计算、成本固定，采样数和分辨率可随手按硬件缩放。

它和普通 SSAO / GTAO 后处理的差别在两件事：

- **固定表面厚度**。传统方法把深度图当高度场，遮挡物"背后无限厚"，栅栏、栏杆、梯子这类薄物体后面会被压黑一圈、还拖光晕，只能靠 falloff 硬凑。本方法给每个样本一个固定厚度，光能从薄物体**背后绕过去** —— 栅栏后面该亮还是亮。
- **可见性位掩码自带方向信息**。每个切片的半球被离散成 32 个扇区，用一个 `uint` 记录哪些方向被挡。因为知道"哪边没被挡"，同一趟采样就能把邻居物体反弹过来的颜色收集回来 —— 间接光带着物体的固有色，画面会"落地"很多。

## 特点

- **AO + 间接光一次追踪** —— 论文 Algorithm 1：样本能贡献的间接光 = 它盖住且尚未被更近样本挡住的扇区占比 × 光照缓冲 × 两项余弦
- **薄物体不压黑** —— 固定厚度建模，栅栏 / 栏杆背后不糊、不拖光晕，不需要 falloff
- **乘性合成** —— `场景色 × (1 + 间接光) × AO`，不是加雾；间接光开大也不会糊成一片
- **卡通分层** —— 把 AO 可见性量化成 N 档，漫画式硬边阴影（与体积光的分层同一手感）
- **半分辨率追踪 + 双边模糊 + 深度感知上采样** —— 全程带深度相似度权重，遮挡不跨深度边缘渗色
- **距离淡出** —— 远处采样密度不够的地方直接淡出，不在远端撒噪点
- **调试视图** —— 一键看可见性或间接光贡献，调参不用靠猜

## 快速设置

1. 把 Feature 装进渲染器：菜单 **Tools > SSIL > Setup In Renderer**
   （或手动在 Renderer Features 里 Add "Screen Space Indirect Light"）
2. 场景里放一个 **Global Volume**，Profile 里 **Add Override > CartoonRendering > Screen Space Indirect Light**
3. 把 **Intensity** 从 0 调到 1 左右
4. 想只看间接光的话把 **AO Strength** 归零、**Debug** 切到 Indirect —— 反弹光贡献看得清清楚楚

> **Intensity 默认是 0。** 与包内其他 Volume 组件一致：`VolumeManager` 对没被覆盖的组件也返回默认实例，默认非 0 会变成「没放 Volume 也生效」。

## 参数速查

### 主控

| 参数 | 说明 |
| --- | --- |
| `Intensity` | 总强度，0 = 完全关闭（默认） |
| `AO Strength` | 环境光遮蔽强度。1 = 完整 AO，0 = 只留间接光 |
| `Indirect Strength` | 间接光强度。乘性叠加，开大也不糊 |
| `Indirect Tint` | 间接光染色。白色 = 忠实还原反弹光颜色，可往暖 / 冷偏做风格化 |

### 采样

| 参数 | 说明 |
| --- | --- |
| `Radius` | 采样半径（世界米）。半径内的物体才产生遮挡 / 反弹光，越大越柔和 |
| `Thickness` | 表面厚度（世界米）。核心参数：调小光更容易"穿过"薄物体，调大会在厚物体边缘漏光 |
| `Sample Count` | 每个切片向外的采样次数。4 是平衡点，半径调大时同步调大 |
| `Slice Count` | 切片（屏幕方向）数量。4~6 够用，8 接近收敛 |
| `Jitter` | 抖动强度。静态抖动（按像素坐标取种子），静止画面不会闪 |

### 范围

| 参数 | 说明 |
| --- | --- |
| `Max Distance` | 效果最远距离（米） |
| `Distance Fade` | 从最远距离的百分之几开始淡出 |

### 质量与风格化

| 参数 | 说明 |
| --- | --- |
| `Blur Radius` | 模糊步长（低分辨率纹素）。追踪必须配合模糊才有平滑结果 |
| `Banding` | 卡通分层档数。0 = 平滑，2~4 是比较好用的档数 |
| `Debug` | `Visibility` 看遮挡（白 = 无遮挡），`Indirect` 看间接光贡献 |

## 它是怎么工作的

每个像素在屏幕平面上取若干**切片方向**，沿方向由近到远采样深度：

1. 每个样本有"前表面角 θf"和"后表面角 θb"（前表面沿视线向后推 `Thickness` 得到），两角之间就是这个样本占的立体角；
2. 把这个角度区间映射成 32 个扇区里的一个**位区间**，置进该切片的位掩码；
3. 该样本能贡献的间接光正比于**它盖住、且之前没被挡住的扇区数 / 32** —— 后面的样本被前面的挡住就自然不出光；同时把它的扇区并进掩码；
4. 切片结束时 `AO = 1 - 置位扇区数 / 32`。

角度以**投影法线**为中心铺满整个半球，切平面以下（表面背后）的角度夹到边缘 —— 这就是"无限厚只挡到掠射角为止"的由来。

## 已知限制

- 纯屏幕空间：光源 / 遮挡物出屏时会缺失，这是所有屏幕空间方法的通病（论文同样）
- 低采样数下结果偏噪，**必须**配合模糊；想要更干净就加 `Sample Count` / `Slice Count`
- 参数需要按场景尺度微调：大世界调大 `Radius`，密集小场景调小 `Thickness`
- 间接光用的是不透明场景色拷贝（`_CameraOpaqueTexture`）当"直接光缓冲"，透明物体不参与反弹
