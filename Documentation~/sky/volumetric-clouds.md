# 体积云

基于光线步进（Ray Marching）的卡通体积云，渲染在**半分辨率** RT 上再上采样合成，带时序累积抗条带。

## 渲染管线

```
全屏三角形（半分辨率 RT）
  → 光线与水平云层平板 [baseY, baseY+thickness] 求交
  → 固定步数步进，逐步采样密度场
  → 密度场 = 128³ Perlin-Worley 噪声 × 积云高度剖面 - Worley 细节侵蚀
  → 朝太阳二次步进 → Beer 透射率 + Powder 边缘增亮
  → 累积亮度 cel 量化（卡通明暗分区）
  → 时序累积（ping-pong 历史缓冲 + 重投影混合）
  → 天空盒 pass 双线性上采样合成
```

相机在云层下方、内部、上方都适用。

## 关键参数

| 参数 | 说明 |
| --- | --- |
| Coverage | 云量（0 无云 → 1 满天） |
| Base Height / Thickness | 云层高度范围 |
| Density | 整体密度 |
| March Steps | 步进次数（8~48，质量/性能开关） |
| Shade Steps | 卡通明暗分区数 |
| Silver Intensity / Power | 逆光银边 |
| **Temporal Enabled** | 时序累积（TAA）开关，见下文 |
| Temporal | 累积权重（越高越平滑，快速运镜会有拖影） |

完整参数表见[天空系统参数参考](/reference/sky-parameters#体积云)。

## 时序累积（TAA）开关

体积云使用每像素哈希 jitter 打散步进切片，再靠时序累积在几帧内收敛掉噪点。

- **开启（默认）**：运动几帧后云面干净平滑，游戏相机专用
- **关闭**：不分配历史缓冲（省内存）、jitter 自动冻结为静态图案（避免无累积时的闪烁噪点）。适合单帧截图或完全不想看到拖影的场景

Scene 视图 / 预览相机始终走"全新渲染"路径，不占用历史缓冲。

## 抗条带设计（v1.0.1）

远距离体积云的步进条带问题通过以下手段消除：

1. **步进范围收紧**：终点钳制到大气透视淡出距离（baseY×16），无无效步进
2. **距离自适应噪声 LOD**：每步按步长与像素足迹选择噪声 mip（奈奎斯特偏置），细节侵蚀随 LOD 淡出
3. **高度剖面自适应加宽**：云底 / 云顶斜坡随步长加宽，远处保持连续采样
4. **满步长 jitter**：±0.9 步长的每像素哈希抖动

## 性能

- 半分辨率渲染，上采样合成
- 默认 40 步进 + 5 步光照，中端 GPU 可流畅运行
- 关掉 Temporal 可省掉两块 960×540 历史缓冲
