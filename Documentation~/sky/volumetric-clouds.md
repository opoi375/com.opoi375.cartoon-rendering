# 体积云

基于光线步进（Ray Marching）的卡通体积云，渲染在**半分辨率** RT 上再上采样合成，带时序累积抗条带。

![体积云：一朵朵分得开的积云、卡通明暗分区与逆光边缘](/sky/volumetric-clouds.webp)

## 噪声是叠出来的（这一节是重点）

云好不好看，几乎全押在密度场上。**单层 3D 噪声做不出好看的云** —— 它在统计上是各态历经的，铺满天空就是一块均匀的磨砂玻璃。这里叠了四层，每层只管一件事：

| 层 | 来源 | 管什么 |
| --- | --- | --- |
| 天气（2D，低频） | `Textures/CloudShape2D.asset` R / G | **哪一片天有云**。让云聚成云系，之间留出真正的蓝天 |
| 形状（3D，中频） | `Textures/CloudNoise3D.asset` R | 一朵云的轮廓（Perlin-Worley 积云团） |
| 域扭曲（2D，低频） | `CloudShape2D` B / A | 把 3D 采样坐标推一把，云缘卷起来而不是圆滚滚 |
| 侵蚀（3D，高频） | `CloudNoise3D` G / B / A | 边缘的椰菜花碎口 |

两张图都由 `Tools > Cloud > …` 烘焙，都做过 **CDF 直方图归一化**（下一节），包内自带，开箱即用。

## 为什么必须做 CDF 归一化

密度取自 `smoothstep(1 - coverage, 1 - coverage + soft, r)`。这个式子只有在 `r` 铺满 0..1 时才有意义。

旧烘焙用 Schneider 的 Perlin-Worley 组合 `pw = (perlin - (1 - worley)) / worley`，它在 `worley` 小的地方**整片塌成精确的 0** —— 实测旧资产里约一半体素是 0。于是 coverage = 0.5（阈值 0.48）几乎没有东西能过，天空是空的；把 coverage 拉到 0.95 才挤出几团。

现在烘焙末尾加一步 CDF 归一化：按直方图把每个通道重映射到均匀分布。单调映射不动空间关系，云的连通结构完整保留，只换来一件事 —— **coverage 就是字面的"天空被遮住的比例"**：0.24 = 24%，滑到哪儿都所见即所得。

归一化救不了"并列"：一半样本挤在同一个值上时，重映射后仍然是一整块常数，coverage 滑过那个值会让云量从 0% 直接跳到 50%。所以先把 `perlin` 按 12% 混回 `pw`，给死区留下排序信息。

## 采样坐标必须世界锚定

天气图早期跟着 3D 形状一起"以相机为原点重新居中"，于是采样窗口永远钉在 uv≈0 —— 头顶这片天看到的永远是图块的同一个角落，天气调制直接退化成常数。这个坑是靠 `Weather` 调试视图整屏一个灰度定位到的。

现在两张图都用绝对世界坐标 + `frac()`（Repeat 环绕下完全等价，只是把数值压回 float 精度舒服的范围）。飞到哪里是什么天气，才是天气图存在的意义。

![仰视：云顶亮、云底冷灰，分区干净](/sky/volumetric-clouds-overhead.webp)

## 关键参数

| 参数 | 说明 |
| --- | --- |
| Coverage | 云量。**做过 CDF 归一化后它就是字面占比**（0.2~0.3 是分得开的积云，0.5+ 开始连成甲板） |
| **Weather Scale** | 天气图世界尺度。0.0002 → 一块天气图 5 km，云系约 1.5 km |
| **Weather Contrast** | 天气在局部把覆盖度推开多少。0 = 均匀天空（旧行为），1+ = 强聚团 |
| **Weather Detail** | 大尺度云系 ↔ 中尺度单朵云的混比 |
| **Warp** | 域扭曲强度（噪声图块单位），卷边用 |
| Base Height / Thickness | 云层高度范围。积云要"孤岛"就别把厚度给太大 |
| Scale | 3D 形状尺度。0.00065 → 一块 1.5 km，单体云约 400 m |
| Density | 整体密度 |
| Detail | 高频侵蚀强度，椰菜花边缘 |
| March Steps / Light Steps | 步进次数（8~48 / 2~8） |
| Shade Steps / Smooth | 卡通明暗分区数与边界软化 |
| Silver Intensity / Power | 逆光银边 |
| **Debug** | 六个调试视图，见下 |
| Temporal Enabled / Temporal | 时序累积开关与权重 |

完整参数表见[天空系统参数参考](/reference/sky-parameters#体积云)。

## 调试视图（`volCloudDebug`）

"整屏没有云"和"云画了但你看不见"用眼睛分不出来，只能把中间量画出来：

| 视图 | 正常应该看到 | 不正常说明什么 |
| --- | --- | --- |
| `Coverage` | 成片的云块 | 整屏黑 = 密度模型没吃到东西（阈值或噪声分布问题） |
| `MarchRange` | 有数值 | **纯红 = 射线根本没穿过云层**（云底设得太低 / 太薄） |
| `Field` | 有明暗颗粒 | 整屏均匀灰 = 噪声被 mip 抹平了 |
| `Profile` | 云层中部亮 | 整屏黑 = 高度剖面把云整个裁掉了 |
| `Lod` | 近处低、远处高 | 普遍偏高 = 步进数不够，细节全丢 |
| `Weather` | 大片深浅分区 | 整屏一个灰度 = 天气图没接上（引用丢了，或尺度太小） |

## 渲染管线

```
全屏三角形（半分辨率 RT）
  → 光线与水平云层平板 [baseY, baseY+thickness] 求交
  → 固定步数步进，逐步采样密度场
  → 密度场 = 天气(2D) 调制覆盖度 → 形状(3D) → 域扭曲 → 高频侵蚀 → 高度剖面
  → 朝太阳二次步进 → Beer 透射率 + Powder 边缘增亮
  → 累积亮度 cel 量化（卡通明暗分区）
  → 时序累积（ping-pong 历史缓冲 + 重投影混合）
  → 天空盒 pass 双线性上采样合成
```

相机在云层下方、内部、上方都适用。

## 抗条带设计

1. **步进范围收紧**：终点钳制到大气透视淡出距离（baseY×16），没有无效步进
2. **距离自适应噪声 LOD**：每步按步长与像素足迹选 mip（奈奎斯特偏置）
3. **LOD 对比补偿**：取 mip 会把场拉向均值 0.5，固定阈值下**远处的云会因为"被抹平所以过不了阈值"而整片消失**。按 lod 把偏离量放大回去（上限 1.8×，不封顶会在远处撒一圈白盐粒）；阈值软带同步放宽，避免残余噪声读成锯齿边
4. **高度剖面自适应加宽**：云底 / 云顶斜坡随步长加宽，远处保持连续采样
5. **满步长 jitter**：±0.9 步长的每像素哈希抖动
6. **银边按密度门控**：薄边缘拿到满强度阳光会在轮廓外撒白点，且时序收敛之后依然存在（不是抖动，是真的画错了）

地平线带交给大气透视，不靠硬窗口切：早期 `smoothstep(0.02, 0.14)` 会把 0~8° 挖空，而平流云层通常是关着的，于是天上出现一条"没有任何云"的带子。

## 时序累积（TAA）开关

体积云用每像素哈希 jitter 打散步进切片，再靠时序累积在几帧内收敛掉噪点。

- **开启（默认）**：运动几帧后云面干净平滑，游戏相机专用
- **关闭**：不分配历史缓冲（省内存）、jitter 自动冻结为静态图案。适合单帧截图或完全不想看到拖影的场景

Scene 视图 / 预览相机始终走"全新渲染"路径，不占用历史缓冲。

## 性能

- 半分辨率渲染，上采样合成
- 默认 32 步进 + 6 步光照，中端 GPU 可流畅运行
- 关掉 Temporal 可省掉两块历史缓冲
- 天气层每步多一次 2D 采样，代价可以忽略
