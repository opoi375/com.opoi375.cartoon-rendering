# 体积云

半分辨率 RT 上光线步进的卡通体积云，天上的云由它**一家**负责。

![体积云：离散云团，朵与朵之间留着天空](/sky/volumetric-clouds.webp)

## 为什么以前的云"就是一团"

旧模型把 3D 噪声按覆盖率阈值化。连续随机场有一个**渗流阈值**（约 0.3）：覆盖率一过它，整块场就**拓扑连通**了 —— 所以不管怎么加噪声、加侵蚀、加明暗，天空看起来都是一整团或一整块甲板。**这是拓扑问题，不是参数问题。**

新模型把密度建成**离散云团实例**：

```
世界平面按 volCloudSpacing 切成 cell
  → 每个 cell 最多住一朵云（独立哈希决定：有没有、多大、多厚）
  → 密度 = 各候选云团的椭球剖面取最大值
  → 半径剖面 (1 - h²)^dome：底部平（凝结面）、顶部收成圆顶
  → 轮廓用低频 FBM 做域扭曲 + 表面带高频侵蚀 → 卷曲的椰菜花边
```

cell 之间**天然有留白**，每朵云的半径与厚度又各不相同，读起来才像"天上有几朵云"。

## 噪声是怎么叠的

云的形状不是"一个场阈值化"，而是**五层叠加，每层只管一件事**。全部在着色器内程序化（无烘焙资产），但**类型必须对**：

| 层 | 用什么 | 负责 | 用错会怎样 |
| --- | --- | --- | --- |
| L1 | cell 实例（哈希摆放） | 大尺度的朵与朵、以及朵之间的留白 | 换成连续场 → 渗流成"一整块甲板" |
| L2 | **billow(值噪声)** 低频 | 轮廓扭曲：鼓包、收腰、拉长 | 用普通 FBM → 只是整体晃动，还是圆球 |
| L3 | **billow(Worley)** | 菜花折痕、大瓣 | 用值噪声 → 只能啃圆角，永远不像菜花 |
| L4 | **billow(值噪声)** 中频 | 把大瓣再撕开、出毛边 | 缺这层 → 轮廓是一圈同粒度的锯齿 |
| L5 | **billow(值噪声)** 内部 | 云芯的密疏差 | 缺这层 → 云内部光照完全均匀 |

两个关键细节：

1. **`billow(n) = 1 - |2n - 1|`** 把平滑场折成脊：凸处更凸、凹处收成缝。"鼓包 + 收腰"就是这个折叠给的，普通 FBM 堆多少倍频都只是高斯软球。
2. **Worley 的胞边**才是菜花的折痕来源；值噪声给不出锐利的折面。
3. **每朵云要有自己的噪声相位**：噪声在世界空间取样，如果不按云的哈希偏移，同一片噪声会套在每朵云上 —— 天上会出现一排一模一样的云（实测如此）。

密度合成：`density = shape × 1.5 - carve × detail × 1.1`，其中 `shape` 是**归一化径向梯度**（1 = 云芯，0 = 表面）。**径向梯度必须铺满整个体积** —— 早期版本只用一条 27m 的薄软边，密度等于二值，噪声只能啃到皮，渲出来就是"白药丸"。

## 关键参数

| 参数 | 说明 |
| --- | --- |
| **Spacing** | cell 间距（米）。朵与朵的留白由它决定 |
| **Coverage** | 一个 cell 是否住着云。平滑淡入（调它不会逐个 pop），同时被天气场上下推 |
| **Size** | 云团半径占 cell 的比例。大致 ×2 ≈ 两朵云最窄处 |
| **Size Jitter** | 半径随机度。0 = 每朵一样大 |
| **Weather** | 大尺度天气调制（波长 = 8 个 cell）。天上有云系分区（这边成片、那边一片空），而不是均匀撒糖 |
| **Base Height / Thickness** | 云底高度与单朵云最大厚度。每朵按 Height Jitter 变薄变厚 |
| **Dome** | 圆顶指数：0.25 = 宽而扁（层云），0.7 = 圆墩（积云）。底永远是平的 |
| **Warp** | 轮廓域扭曲。把采样点推开，云缘变成卷的而不是圆的 |
| **Noise Freq** | 扭曲 / 侵蚀噪声的频率。500m 的云配 0.002 合适；太大碎成粉刺，太小变成大块光斑 |
| **Detail** | 边缘侵蚀。0 = 光滑椭球，1 = 重度椰菜花咬口 |
| **Density / March Steps / Light Steps** | 消光与步进（质量 / 性能开关） |
| **G Forward / Backward / Phase Forward / Scatter Octaves** | 双叶 HG 相位函数 + Wrenninge 倍频多重散射 |
| **Aerial Perspective** | 远处云按"消光 + 内散射"染进天空色，而不是只淡出 alpha |
| **Wind Speed** | 风速。整片云团网格随风平移 |
| **Shade Steps / Smooth / Silver \*** | cel 明暗分区与逆光银边 |
| **Temporal Enabled** | 见下方"已知问题"，默认关闭 |
| **Debug** | 七个调试视图，见下 |

完整参数表见[天空系统参数参考](/reference/sky-parameters#体积云)。

## 调试视图（`volCloudDebug`）

"天上没有云"和"云画了但看不见"用眼睛分不出来，只能把中间量画出来。这次重写里三个 bug 全是靠这几个视图定位的。

| 视图 | 正常应该看到 | 不正常说明什么 |
| --- | --- | --- |
| `Coverage` | **一颗颗分明的椭圆云团**，之间是黑的 | 连成一片 = 间距太小或尺寸太大 |
| `Instance` | 大面积亮（cell 活着），带零星暗块 | 整屏暗 = 覆盖率太低，云朵稀到看不见 |
| `Height` | 竖向渐变 | 纯色 = 剖面没生效 |
| `Edge` | 云轮廓上的一圈线 | 没有 = 侵蚀没生效，云缘会是光滑椭球 |
| `Depth` | 有值 | **纯红 = 射线根本没穿过云层**（云底太高 / 太薄） |
| `Scatter` | 随角度变化 | 一片 = 相位函数没生效 |
| `积分诊断`（第 7 项） | **纯黄 = 又厚又亮** | 偏红 = 云太薄；偏绿 = 云太暗。一次抓图就能分辨 |

## 性能：着色器编译

`Worley3` 是 27 邻域搜索。**绝对不要用 `[unroll]`** —— `CloudDensity` 会在主步进（最多 64 次）、朝太阳的光照步进（最多 8 次）和调试视图里各内联一份，展开后等于把 27×3 次哈希复制到几百个调用点，D3D11 编译器会卡在 99% 好几分钟（实测 72 秒仍在跑）。用单层 `[loop]`，并让**自阴影步进走廉价路径**（`detailMul = 0`，跳过 Worley）：改后同一份着色器重编译约 5 秒。

## 已知问题

- **时序累积（`volCloudTemporalEnabled`）会把云压成半透明薄雾，所以默认关闭。** 历史缓冲的亮度系统性低于当前帧，0.3 权重仍可见。已加"至少渲染过一帧才采样历史"的保护，但根因未解决，修好之前别打开。
- 云内部偏平：cel 分区（默认 3 档）把内部明暗压成了大片同色，想要更多内部层次就调低 `Shade Steps` 或提高 `Shade Smooth`。
- 地面没有云影。文献里这是"云看着假"的头号线索，需要新增一个 pass 与若干光照挂钩，尚未实现。

## 渲染管线

```
全屏三角形（半分辨率 RT）
  → 射线与云层带求交（baseY ~ baseY + 最大厚度）
  → 固定步数步进；每步查 3×3 cell 找最近的云团，算椭球剖面 + 腐蚀
  → 朝太阳二次步进求自阴影 → 双叶 HG 相位 × 多重散射
  → 均匀薄片的能量守恒积分（L 已是入射辐射，所以是 L·(1 - Tstep)）
  → 大气透视（代表深度处染进天空色）
  → cel 量化（一次性量化累积亮度，不逐片，否则出条带）
  → 天空盒 pass 双线性上采样合成
```
